# Участие в разработке mLib

Спасибо за желание помочь. Перед крупным изменением сначала создайте issue: так проще согласовать UX, миграции и границы модулей.

## Локальная подготовка

Используйте Python 3.12+, Node.js 22+, pnpm 11+ и FFmpeg. Команды установки backend и frontend приведены в README. Никогда не используйте рабочую базу или настоящую медиатеку для тестов.

## Проверки перед pull request

```bash
cd backend
python -m pytest
ruff check app tests

cd ../frontend
pnpm typecheck
pnpm lint
pnpm build
pnpm test:e2e
```

В pull request кратко опишите пользовательский эффект, миграции и выполненные проверки. Не добавляйте `.env`, базы, медиафайлы, токены, логи и generated output. Для исправления UI приложите актуальные снимки до/после, если они помогают ревью.
