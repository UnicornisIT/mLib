# mLib для Windows

## Установка

1. Скачайте файл `mLib-Setup-0.0.3-alpha-x64.exe`.
2. Запустите его двойным щелчком.
3. Следуйте подсказкам установщика.
4. После установки откройте mLib с рабочего стола или из меню «Пуск».

Тестовые сборки без цифровой подписи могут вызвать предупреждение Windows о неизвестном издателе. Для публичного выпуска используйте installer из официального релиза mLib и сверяйте опубликованную SHA-256 сумму.

Python, Node.js, Docker и база данных отдельно не нужны.

## Первый запуск

При первом запуске mLib сам создаст локальную базу и нужные папки. Затем придумайте имя пользователя и длинный пароль. Все разделы mLib используют этот вход.

## Где хранятся данные

Программа установлена отдельно от вашей библиотеки. Коллекция находится здесь:

```text
%LOCALAPPDATA%\mLib
```

Обычно это путь вида:

```text
C:\Users\ВашеИмя\AppData\Local\mLib
```

Внутри находятся базы, изображения, музыка, видео, книги, резервные копии и журналы. Не изменяйте содержимое папок `data` и `media` вручную во время работы mLib.

## Резервная копия

Откройте:

```text
Настройки → Данные → Создать резервную копию
```

Выберите место сохранения. Получится файл `mLib-backup-....zip` со всеми базами, медиафайлами и пользовательскими настройками.

Для восстановления выберите:

```text
Настройки → Данные → Восстановить резервную копию
```

mLib сначала автоматически сохранит текущее состояние, затем восстановит выбранную копию.

## Экспорт для переноса

Откройте:

```text
Настройки → Данные → Экспортировать библиотеку
```

Файл `mLib-export-....zip` содержит все записи, связи и media в переносимом формате. Используйте его для переноса на другой ПК, а в будущем — на серверную версию mLib.

Чтобы загрузить такой архив:

```text
Настройки → Данные → Импортировать библиотеку
```

Перед импортом mLib проверяет архив и создаёт резервную копию текущей библиотеки. Не закрывайте программу до завершения операции.

## Обновление

mLib автоматически проверяет новые стабильные версии после запуска и затем несколько раз в день. Если обновление доступно, внутри программы появится панель с номером версии и кнопкой `Скачать`.

После загрузки нажмите `Перезапустить и установить`. mLib корректно закроет локальные службы, запустит установщик и снова откроется уже в новой версии. Проверить обновления вручную можно здесь:

```text
Настройки → О программе → Проверить сейчас
```

Если панель закрыть, обновление можно скачать позже через этот же раздел. База и media находятся отдельно от программы, поэтому обновление их не удаляет. Перед изменением структуры базы mLib также создаёт автоматическую резервную копию.

Самая первая версия с поддержкой автообновления устанавливается обычным installer из GitHub Releases. Дальнейшие версии программа предложит сама.

## Удаление и повторная установка

Удалить программу можно через:

```text
Параметры Windows → Приложения → mLib → Удалить
```

По умолчанию библиотека в `%LOCALAPPDATA%\mLib` остаётся на компьютере. Если позже установить mLib снова, программа обнаружит прежние данные.

Если вы хотите навсегда удалить и программу, и всю библиотеку, сначала сделайте нужный Export/Backup, удалите mLib, а затем вручную удалите `%LOCALAPPDATA%\mLib`.

## Если mLib не запускается

Сообщение об ошибке предложит открыть папку журналов. Её также можно открыть через:

```text
Настройки → О программе → Открыть папку журналов
```

Основной журнал находится в `%LOCALAPPDATA%\mLib\logs\mlib.log`.
