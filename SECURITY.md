# Security Policy

## Поддерживаемая версия

До первого стабильного релиза исправления безопасности выпускаются только для последней версии основной ветки.

## Сообщение об уязвимости

Не создавайте публичный issue с эксплойтом, токенами, приватными путями или пользовательскими данными. Используйте приватный канал владельца репозитория либо GitHub Private Vulnerability Reporting после включения этой функции.

В сообщении укажите затронутую версию, минимальные шаги воспроизведения, ожидаемый риск и возможное исправление. Не проверяйте уязвимость на чужих экземплярах mLib без явного разрешения.
